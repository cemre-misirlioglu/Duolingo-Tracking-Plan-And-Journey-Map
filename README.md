Mapped the user journey in the Duolingo app across key stages, including registration, onboarding, first lesson, engagement, and subscription. Created an event tracking plan defining the events and properties needed to monitor user behavior throughout these stages. Specified key metrics and calculation methods, including signup and onboarding completion rates, step progression rates, and first lesson start and completion rates. Also defined user properties for tracking learning preferences, onboarding progress, and subscription status.
